# Omarecorder 1.0 — design addendum (2026-08-30)

Approved design for the 1.0 sprint. Extends `2026-08-29-omarecorder-design.md`.

## Scope

1.0 = the v0.2 roadmap (chunked transcription, live input meter, popup import; playback scrubber + waveform + trim gated by a QtMultimedia spike) plus *Send to Obsidian*. Dropped from the roadmap: whisper-cpp, sherpa-onnx (new packages). Deferred to 1.x: AI clean-up/summary, speaker attribution, per-track transcripts.

Principles: local-first, Omarchy-native, no new packages, no polling, secure by default (0600 files, runtime state only in `$XDG_RUNTIME_DIR`, no shell strings built from data).

## Feature designs (from the design pass; grounded in current line numbers)

### B0 Groundwork (do before B1–B5; several audit fixes live here)
* `bin`: `locked()` wrapper with `flock -w 5` on `$RUN_DIR/state.lock` around
  `state_set`/`bump_state`/`reconcile_state` (Q2). `run_detached` adds
  `--setenv=XDG_RUNTIME_DIR --setenv=HOME` (Q5). Extract `mix_both <dir>` from
  `record_stop:283-287` and `repair_wav <file>` from `repair_audio`; `reconcile_state`
  repairs+mixes `mic.wav`+`system.wav` when `audio.wav` is absent (Q3), and `amix`
  failure is fatal (Q4). `_dl_worker` writes `bytes_done` into its state job every 2 s
  (today the download progress bar never gets real data).
* `Service.qml:160-163`: timer → `updateElapsed()` only; list refresh solely on
  `version` change (B6).

### B1 Chunked / incremental transcription
* `CHUNK_S=${OMARECORDER_CHUNK_S:-1800}`; `dur ≤ CHUNK_S` → unchanged single pass.
  Else `chunks = ceil(dur/CHUNK_S)`, equal lengths (54 min → 2×27, never a tiny tail).
* **No overlap** (voxtype has no timestamps, so text-dedupe would re-create the very
  duplication we're removing). Seams snap to silence: `seam_near` runs
  `ffmpeg -ss t-15 -t 30 … -af silencedetect=n=-35dB:d=0.4` and picks the nearest
  silence midpoint, falling back to `t`.
* `_tx_worker` becomes a loop in the **one existing unit**: per piece → `state_set`
  `progress:{chunk,chunks}` (version bump → UI), `ffmpeg -ss/-to -c copy` to
  `$RUN_DIR/tx-<id>.chunk.wav`, voxtype as today, append to `transcript.md.tmp`,
  atomic publish of `transcript.md` with header `… chunks=N partial=true`, meta
  `transcript.{partial,chunks,chunks_done}`. After the loop: final header, `learn_rtf`
  (factored out of `:585-588`), meta `partial:false`, notify. TERM trap: learn rtf from
  audio done so far, kill own children, clean tmp, exit 0 (cancel keeps the partial).
  `transcript.prev.md` copied on the first successful piece. `--from/--to` validated
  (`valid_seconds`, `to > from`) before the job is registered (S5).
* UI: `Service.jobProgressText(j)` → "2/4 · "; used in `Panel.qml:36` stateText,
  `RecordingRow` subtitle, `Library.qml:414-424` progress line. Partial text already
  streams in via the existing `transcriptFile` FileView. One `Text` above the
  transcript when `partial && !job`: "Partial — cancelled after n/N pieces. Re-transcribe
  to finish."

### B2 Live input meter + clip indicator
* `record_start` spawns `setsid "$SELF" _meter <target> <recorder_pid>` (mic for
  mic/both, monitor for system) → `ffmpeg -f pulse -i <target> -af
  "aformat=…mono,asetnsamples=n=4000,astats=metadata=1:reset=1:measure_overall=Peak_level+Peak_count,ametadata=print:file=-" -f null -`
  piped into `_meter_loop` (pure bash, unit-testable): skips `pts_time < 1.0` (start
  transient), writes `{"peak_db","clip","t"}` atomically to `$RUN_DIR/level` ≤ 4 Hz;
  clip = `peak > −0.5 dB && count ≥ 2`, held 1.5 s; `kill -0 <recorder>` watchdog.
  Meter pid stored as `recording.meter_pid` (separate from `pids`, so a live meter can't
  mask a dead recorder). `record_stop`/`reconcile_state` kill it and remove the file.
  Meter failure never fails a recording.
* UI: second `FileView` in Service bound to `levelFile` only while recording (zero idle
  cost); new `ui/LevelMeter.qml` (track + fill, urgent colour + "CLIP" caption while
  clipping) under `PanelHero` in the popup and under the meta line in the Library for
  the live take. Bar widget: label shows `CLIP` instead of the timer while clipping (the
  glyph is already urgent-coloured; no new geometry).

### B3 Playback scrubber + waveform + trim (spike-gated)
* **Spike** (≤30 min): `.spike/player.qml` (git-ignored) with `MediaPlayer` +
  `AudioOutput`, run via `qs -p`; pass = audible, `position` ticks, seek by assignment
  works, source swap doesn't crash; confirm once in-shell inside a
  `Loader { active: opened }`. **Fallback**: `cmd_play --input-ipc-server=$RUN_DIR/mpv.sock`
  + `Quickshell.Io.Socket` with `observe_property time-pos` — event-driven, no polling.
* `make_waveform <dir>`: `showwavespic=s=800x64:colors=#888888:scale=sqrt` from
  `finalize_audio` (stop/import/recovery) and `trim`. `rec_json` adds `waveform`, `has_orig`.
* `cmd_trim <id> --from s --to s [--replace] | --restore`: validated; refused while
  recording/transcribing; `-c copy`; first original kept as `audio.orig.wav`;
  re-finalize + levels + waveform; meta `trim:{from,to,at,original}`;
  `transcript.stale=true` (cleared by the next transcription). `--restore` reverses it.
* UI: new `ui/Waveform.qml` = `Image` (cache-busted by size) + kit `PanelSlider`
  restyled as scrubber/played-region; trim mode adds two draggable handles + dimmed
  outside region. Library: scissors action → trim row "From · To · Preview · Trim ·
  Cancel" → `ConfirmDialog` → `svc.trim`. Meta line " · trimmed", stale notice above the
  transcript, "Restore original" when `has_orig`. Space/Left/Right on the player.

### B5 Send to Obsidian
* Config: `obsidianVault: ""`, `exportDir: ""` (empty = automatic).
* `cmd_vaults --json`: from `~/.config/obsidian/obsidian.json` + each vault's
  `.obsidian/app.json` → `[{path,name,open,ts,newFileLocation,folder}]`, open first, then
  `ts` desc; missing vault dirs dropped.
* `resolve_export_target`: `--dir` → dir; `--vault`/config vault → must exist (die,
  never silently pick another); else first of `vaults`; else `exportDir`; else the
  recording folder.
* `cmd_export <id> [--vault|--dir] [--no-open]`: note name = sanitized title with
  Obsidian-illegal chars → `-`, collisions → " (2)"; YAML frontmatter (title, date,
  duration, source, model, `omarecorder: <id>`, `partial`/`stale` when true,
  `tags: [omarecorder]`) + transcript body without the header comment; meta
  `exported_to/exported_at`; `xdg-open obsidian://open?path=<@uri>` only when a vault
  was used. (Handler verified: `x-scheme-handler/obsidian` → `obsidian.desktop`.)
* UI: "Send to Obsidian" `PanelActionButton` in the transcript toolbar with a "Sent"
  flash; settings `Dropdown` "Obsidian vault" (Automatic + detected vaults), hidden when
  none detected.

### Data-model diff
```
state.json      recording.meter_pid · jobs[tx].progress{chunk,chunks} · jobs[dl].bytes_done
$RUN_DIR/       level (while recording) · state.lock · tx-<id>.chunk.wav (transient)
meta.json       transcript.{partial,chunks,chunks_done,stale} · trim{} · exported_to/at
folder          waveform.png · audio.orig.wav
config.json     obsidianVault · exportDir
CLI             copy · trim · vaults · export · _meter · _meter-loop  (+ validated --from/--to)
version         1.0.0 read from manifest.json (single source)
```
